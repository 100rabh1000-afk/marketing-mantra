# Marketing Mantra

Official website starter for the Marketing Mantra exam-preparation channel.

## Website

The homepage is in `index.html` and is ready for GitHub Pages.

## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save.
5. GitHub will provide the public Pages URL.

## Adding PDFs

Create a `pdfs` folder and upload files such as:

- `marketing-exams-01.pdf`
- `marketing-exams-02.pdf`
- `marketing-exams-03.pdf`
- `marketing-exams-04.pdf`

Then change the corresponding `Download` button in `index.html` from the placeholder `#` to `pdfs/filename.pdf`.
